Installation

Clone the repo and run the interactive installer. It handles dependencies, detects existing configs, and lets you pick which components to install.

  • Automated: ./install.sh -y
  • Interactive: Choose components selectively
  • CI/CD: Non-interactive via CLI flags
  • Manual: Copy folders to ~/.claude/

Security: Damage Control

Pre-configured hooks that protect your system:

  • Blocks rm -rf /, git reset --hard
  • Prevents reading .env and credentials
  • Blocks direct push to main/master
  • Enforces --force-with-lease over --force
  • Customizable pattern-based rules

Ralph: Autonomous Pipeline

Full development pipeline from idea to code:

  • Spec Interview — Guided requirements
  • PRD Generation — Product requirements
  • prd.json — Atomic user stories
  • Execution — Autonomous implementation
  • Built-in verification and test output
